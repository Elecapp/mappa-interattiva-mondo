# Mapping Mobility in Late Medieval Europe

An interactive map website for exploring items (objects, documents, records)
connected to human mobility in late medieval Europe. Visitors can browse an
interactive map, click points to see item details, or follow curated
thematic paths (e.g. "Pilgrimage", "Trade Routes") that list their items as
a chronological itinerary, with an intro description and a post feed for
each path.

The site reads its item data from a Google Sheet published as CSV, and a
second Google Sheet (with "descriptions" and "posts" tabs) for each
thematic path's intro text and post feed — both editable by the researcher
without touching code. See
[`docs/DATA-ENTRY-GUIDE.md`](docs/DATA-ENTRY-GUIDE.md) for the
non-technical guide to send her.
